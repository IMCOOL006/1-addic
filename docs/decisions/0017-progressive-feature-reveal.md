# ADR 0017: Feature reveal — progressive, with "Show all features now"

- **Decision:** D17 (PLAN §15) · **Status:** Accepted (default) · **Date:** 16 October 2026

## Decision

Features appear as the Journey reaches them, each with a "New" dot and its just-in-time tutorial. SOS, crisis help, quick-log and check-ins are always visible. A "Show all features now" setting reveals everything at once.

## Consequences

- Built at Step 2.3; the reveal table in PLAN §5.10 is content, not code.

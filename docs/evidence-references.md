# Evidence and sources behind the app

The seed list for the **About & evidence** screen (PLAN §5.12). Every row is a real, primary source or a major guideline, written as the plain-language claim the app may make, the citation, the strength of the evidence, and where the app uses it. Step 2.11 turns this file into `content/references/`; the clinical advisor checks it in Step 6.1.

**Rules.** Primary sources or major guidelines only. State the claim no more strongly than the source does. Say which kind of evidence it is. The app itself is not clinically tested, and the screen says so. The source workbook is credited as the inspiration (title, author, publisher) and is never quoted. Add a "last reviewed" date to each card in the app.

**Verification status (15 October 2026).** Bibliographic details for R4, R5, R6, R10, R12, R13, R16, R20, R21, R22, R24, R25, R26, R30 and R32 were checked against publisher, PubMed Central, Cochrane or library records. The remaining rows are standard citations; confirm each DOI when building `content/references/` (Step 2.11). R17's wording follows how the source workbook describes the study; check it against the paper.

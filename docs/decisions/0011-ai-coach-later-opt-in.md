# ADR 0011: AI coach — later, opt-in, after the friends release

- **Decision:** D11 (PLAN §15) · **Status:** Accepted (default, with timing) · **Date:** 16 October 2026

## Decision

No AI coach in the core app. An opt-in AI rehearsal partner is a nice-to-have: Step 6.4 writes a proposal (design, prompts, crisis routing, data minimisation, evaluation set, costs) after a version is shareable with friends, and nothing is built until the owner approves that proposal.

## Consequences

- SOS stays offline and deterministic. Any AI feature is opt-in per feature, strips names and contacts, and runs behind app-side crisis detection (PLAN §11).

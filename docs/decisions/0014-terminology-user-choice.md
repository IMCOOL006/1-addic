# ADR 0014: Terminology — the person's choice

- **Decision:** D14 (PLAN §15) · **Status:** Accepted (default) · **Date:** 16 October 2026

## Decision

Each person chooses their word (sober, clean, substance-free, in recovery) in onboarding, and the app uses it everywhere. The app's own voice always uses person-first language.

## Consequences

- Copy templates carry the chosen term; Gujarati copy needs an equivalent choice (ADR 0010).
